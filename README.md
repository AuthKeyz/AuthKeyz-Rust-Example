# AuthKeyz-Rust-Example
AuthKeyz Rust example SDK for https://authkeyz.bond license key API auth.

Update the values in the `main.rs` file and you're ready to go!

## **Bugs**

If you have any issues with the underling library make an issue on the library's [Github](https://github.com/D0A1V2I3D/authkeyz-rust)

[Old library](https://github.com/AuthKeyz/AuthKeyz-Rust-Example/tree/backupoldapi)

## **What is AuthKeyz?**

AuthKeyz is an Open source authentication system with cloud hosting plans as well. Client SDKs available for [C#](https://github.com/AuthKeyz/AuthKeyz-CSHARP-Example), [C++ (API 1.3)](https://github.com/AuthKeyz/AuthKeyz-CPP-Example-API_1.3), [C++ (API 1.2)](https://github.com/AuthKeyz/AuthKeyz-CPP-Example-API_1.2), [Python](https://github.com/AuthKeyz/AuthKeyz-Python-Example), [Java](https://github.com/AuthKeyz/AuthKeyz-JAVA-api), [JavaScript](https://github.com/AuthKeyz/AuthKeyz-JavaScript-Example), [VB.NET](https://github.com/AuthKeyz/AuthKeyz-VB-Example), [PHP](https://github.com/AuthKeyz/AuthKeyz-PHP-Example), [Rust](https://github.com/AuthKeyz/AuthKeyz-Rust-Example), [Go](https://github.com/AuthKeyz/AuthKeyz-Go-Example), [Lua](https://github.com/AuthKeyz/AuthKeyz-Lua-Examples), [Ruby](https://github.com/AuthKeyz/AuthKeyz-Ruby-Example), and [Perl](https://github.com/AuthKeyz/AuthKeyz-Perl-Example). AuthKeyz has several unique features such as memory streaming, webhook function where you can send requests to API without leaking the API, discord webhook notifications, ban the user securely through the application at your discretion. Feel free to join https://discord.gg/KNRpCwWANJ if you have questions or suggestions.
